Compare neighboring values and swap them if out of order. Large values bubble rightward until they settle at the end.

Each pass fixes one maximum value

During a pass, the larger value in each comparison moves right, leaving the interval's maximum at the end. The next pass excludes that final position. If a whole pass makes no swaps, the array is sorted and the algorithm stops. This gives O(n) time on already sorted input.

Coding exercises: swaps equal inversions

An inversion is a pair i < j with a[i] > a[j]. Each bubble-sort swap removes exactly one inversion, so the swap count equals the inversion count. For large n, count inversions using Merge Sort in O(n log n), rather than simulating every swap.
