Node i has children 2i+1 and 2i+2, and parent (i−1)//2. sift_down swaps a node with its larger child until the heap property holds. A sift traverses O(log n) levels, and repeated extraction gives O(n log n) sorting time.

Initial heap construction sifts down from the last parent toward the root. Most nodes are near the bottom and move only a short distance, so construction totals O(n), not O(n log n).

Coding exercises: heaps as priority queues

Priority queues are a more common application than manually implementing heap sort. Python's heapq is a min heap; negated numeric priorities can implement a max heap. Keep a size-k min heap to find the largest k values in O(n log k).

import heapq
h = []
for x in a:
    heapq.heappush(h, x)
    if len(h) > k:
        heapq.heappop(h)    # discard the heap minimum
# h contains the largest k values
