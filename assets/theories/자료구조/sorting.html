일곱 가지 정렬이 같은 배열을 동시에 정렬합니다. 모든 알고리즘이 한 번에 한 단계(비교나 이동 한 번)씩 진행하므로, 먼저 끝나는 쪽이 할 일이 적은 알고리즘입니다. 입력 종류를 바꾸면 순위가 달라집니다.

일곱 가지 정렬 알고리즘이 같은 배열을 동시에 정렬하는 경주

입력

[거의 정렬됨]에서는 삽입 정렬과 버블 정렬이 빠르게 끝나고, [역순]에서는 둘 다 가장 느려집니다. 병합 정렬과 힙 정렬은 입력이 바뀌어도 단계 수가 거의 같습니다. 각 정렬의 자세한 과정은 표의 이름을 눌러 확인하세요.

복잡도 한눈에 보기

정렬최선평균최악추가 공간안정
버블O(n)O(n²)O(n²)O(1)예
선택O(n²)O(n²)O(n²)O(1)아니요
삽입O(n)O(n²)O(n²)O(1)예
퀵O(n log n)O(n log n)O(n²)O(log n)아니요
병합O(n log n)O(n log n)O(n log n)O(n)예
힙O(n log n)O(n log n)O(n log n)O(1)아니요
계수O(n + k)O(n + k)O(n + k)O(n + k)예

k는 계수 정렬에서 값의 범위입니다. 안정 정렬은 같은 값끼리의 원래 순서를 유지하는 정렬입니다. 여러 기준으로 차례로 정렬할 때(예: 이름순으로 정렬한 뒤 점수순으로 다시 정렬) 안정성이 필요합니다.

언제 무엇을 쓰나요

보통은 언어의 기본 정렬

파이썬 sort()는 Timsort로 O(n log n)이고 안정 정렬입니다. 직접 짜는 것보다 빠르고 틀릴 일이 없습니다.

최악에도 O(n log n)이 필요할 때

병합 정렬이나 힙 정렬. 메모리가 넉넉하고 안정성이 필요하면 병합, 추가 메모리가 없어야 하면 힙입니다.

거의 정렬된 데이터, 작은 n

삽입 정렬이 가장 빠릅니다. 기본 정렬들도 작은 구간은 삽입 정렬로 처리합니다.

범위가 좁은 정수가 아주 많을 때

계수 정렬. 비교 없이 O(n + k)에 끝나고, 개수만 세면 메모리도 아낄 수 있습니다.

코테에서는: 정렬 기준 다루기

문제의 대부분은 정렬을 직접 구현하기보다 "무엇을 기준으로 정렬하느냐"를 묻습니다. key에 튜플을 주면 앞 원소부터 차례로 비교하고, 내림차순으로 하고 싶은 숫자 기준에는 −를 붙입니다.

a.sort()                                   # 제자리 정렬, 안정
b = sorted(a, reverse=True)                # 새 리스트, 내림차순
people.sort(key=lambda p: (-p[1], p[0]))   # 점수 내림차순, 같으면 이름 오름차순

시간 제한 1초 기준으로 n이 수천 이하면 O(n²)도 통과하지만, n이 10만을 넘으면 O(n log n)이 필요합니다. 파이썬은 C++보다 느리므로 더 보수적으로 잡으세요.
