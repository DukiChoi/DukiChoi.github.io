banner_style: auto로 두거나 생략하면 목록을 열 때마다 스타일을 무작위로 고릅니다. 열 가지를 모두 쓰기 전에는 중복되지 않고, 같은 탭에서 새로고침하면 직전과 다른 스타일을 고릅니다. 직접 지정한 스타일은 고정되며 무작위 배정에서 제외됩니다.

반짝임은 마우스를 올린 동안에만 나타납니다. 기기의 동작 줄이기 설정을 켜면 회전과 반짝임을 멈춥니다.
