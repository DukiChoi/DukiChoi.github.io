글쓰기 화면 열기 →

저장소에 쓰기 권한이 있는 계정으로 이용할 수 있습니다. 저장한 글은 사이트 배포가 끝나면 반영됩니다.

처음 이용할 때
  1. 글쓰기 화면을 열고 DukiChoi GitHub 계정으로 로그인합니다.
  2. GitHub App 연결을 요청하면 Only select repositories를 선택하고 DukiChoi.github.io 저장소만 연결합니다.
  3. master 브랜치에서 이론 자료 글 또는 프로그램 소개를 선택하고 새 글을 작성합니다.

연결은 처음 한 번만 하면 됩니다. 연결 방법 자세히 보기
