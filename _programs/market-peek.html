세 단계면 준비 끝.

  1. 설치 파일 다운로드

    Windows는 EXE 또는 7z, Mac은 Universal DMG를 내려받으세요.

  2. 앱 설치

    Windows는 EXE의 한국어 안내에 따라 설치하거나 7z 압축을 풀어 실행하세요. Mac은 DMG를 열고 Market Peek를 Applications 폴더로 드래그하세요.

  3. 관심 종목 선택

    종목명을 눌러 검색하세요. 가격을 클릭하면 차트를 펼칠 수 있습니다.

Python을 따로 설치해야 하나요?

필요 없습니다. Windows와 macOS 설치 파일에 실행에 필요한 환경이 포함되어 있습니다.

거래소 계정은 어떻게 연결하나요?

앱 설정에서 거래소마다 API 키를 연결하세요. 저장을 선택하면 각 거래소의 키·Secret·필요한 Passphrase를 이 PC에 암호화해 따로 보관합니다.

작은 현물 잔고를 숨길 수 있나요?

설정 → 화면·창에서 현물 숨김 기준을 바꾸세요. 기본값은 평가금액 1 USDT 이하이며, 0으로 설정하면 모두 표시합니다. 선물과 평가금액을 확인할 수 없는 현물은 계속 표시합니다.

최소화와 X·숨기기는 어떻게 다른가요?

작업 표시줄 시세를 켠 상태에서 − 버튼을 누르면 작업 표시줄로 최소화됩니다. X와 숨기기·Alt+H는 트레이로 숨깁니다. 트레이 아이콘이나 Alt+H로 다시 열 수 있으며, 완전히 종료하려면 트레이 메뉴 또는 설정의 앱 종료를 사용하세요. 작업 표시줄 시세를 끄면 − 버튼도 트레이로 숨깁니다. 트레이를 사용할 수 없는 환경에서는 최소화됩니다.

작업 표시줄에 가격이 안 보여요.

앱의 설정 → 화면·창 → 작업 표시줄에 시세 표시를 켜세요. Windows 설정 → 개인 설정 → 작업 표시줄에서 단추 합치기 및 레이블 숨기기를 안 함으로 설정해야 제목이 보입니다. Windows 버전에 따라 설정 이름이 다를 수 있습니다. 시세는 한 줄로 표시되며 공간이 부족하면 잘립니다.

TP·SL의 소수점 표시는 어떻게 되나요?

포지션 라벨과 관련 툴팁은 소수점 한 자리로 표시합니다. 0이 아닌 값이 0.1보다 작으면 <0.1로 표시합니다. 화면 표시만 간결하게 줄이며, 실제 주문 가격과 수량의 정밀도는 유지합니다.

설치 시 Windows 보안 안내가 표시돼요.

현재 설치 파일은 코드 서명되지 않은 개인 개발용 빌드입니다. Windows에서 게시자를 확인할 수 없다는 안내가 나타날 수 있습니다. 배포 출처와 파일을 확인한 뒤 설치 여부를 결정하세요.

Mac이나 휴대폰에서도 사용할 수 있나요?

macOS용 Universal DMG는 Apple Silicon과 Intel Mac을 모두 지원합니다. Windows 전용인 작업 표시줄 시세와 자동 시작 설정은 Mac에서 제공하지 않습니다. 휴대폰에서는 이 다운로드 페이지를 볼 수 있습니다.

Mac에서 개발자를 확인할 수 없다고 표시돼요.

현재 macOS 빌드는 Apple Developer ID 서명과 공증을 받지 않았습니다. 배포 출처와 파일을 확인한 경우, 앱 실행을 한 번 시도한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 차단된 앱의 열기 옵션을 확인하세요.
