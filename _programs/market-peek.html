항상 위로 띄워 두거나, X와 숨기기로 트레이에 넣어 두세요. 기본 단축키 Alt+H로 숨기고 다시 꺼낼 수 있습니다.

클릭 한 번, 펼쳐지는 차트

가격을 누르면 캔들 차트가 펼쳐집니다. 이동평균부터 RSI, MACD까지 10가지 보조지표를 조합하세요.

내가 보는 종목을 한곳에

코인과 한국·미국 주식을 검색하고 즐겨찾기에 담으세요. 코인은 5개 거래소의 차트를 지원합니다.

최소화해도 시세는 한 줄로

설정에서 작업 표시줄 시세를 켜면 − 버튼으로 최소화한 뒤에도 종목·가격·등락률을 확인할 수 있습니다. Windows의 작업 표시줄 레이블 표시 설정이 필요합니다.

현물과 선물을 함께

거래소 API를 연결하면 차트의 시장 선택과 관계없이 현물과 USDT 선물 보유분을 함께 조회합니다. Spot·Long·Short로 구분하고, Upbit는 현물만 지원합니다.

포지션 정보도 간결하게

진입가와 TP·SL을 차트에서 확인하세요. 포지션 라벨과 관련 툴팁은 소수점 한 자리로 표시하고, 지원하는 거래소에서는 기존 TP·SL도 수정할 수 있습니다.

세 단계면 준비 끝.

  1. 설치 파일 다운로드

    EXE 설치 파일을 내려받으세요. 7z 파일은 원하는 폴더에 압축을 모두 풀어 사용합니다.

  2. 한국어 안내로 설치

    EXE는 한국어 안내에 따라 설치하세요. 7z로 받았다면 압축을 푼 폴더에서 Market Peek.exe를 실행하세요.

  3. 관심 종목 선택

    종목명을 눌러 검색하세요. 가격을 클릭하면 차트를 펼칠 수 있습니다.

Python을 따로 설치해야 하나요?

필요 없습니다. Windows용 설치 파일과 7z 파일에는 실행에 필요한 환경이 포함되어 있습니다.

거래소 계정은 어떻게 연결하나요?

계정의 잔고·포지션을 조회하려면 앱 설정에서 거래소 API 키를 연결하세요.

최소화와 X·숨기기는 어떻게 다른가요?

작업 표시줄 시세를 켠 상태에서 − 버튼을 누르면 작업 표시줄로 최소화됩니다. X와 숨기기·Alt+H는 트레이로 숨깁니다. 트레이 아이콘이나 Alt+H로 다시 열 수 있으며, 완전히 종료하려면 트레이 메뉴 또는 설정의 앱 종료를 사용하세요. 작업 표시줄 시세를 끄면 − 버튼도 트레이로 숨깁니다. 트레이를 사용할 수 없는 환경에서는 최소화됩니다.

작업 표시줄에 가격이 안 보여요.

앱의 설정 → 화면·창 → 작업 표시줄에 시세 표시를 켜세요. Windows 설정 → 개인 설정 → 작업 표시줄에서 단추 합치기 및 레이블 숨기기를 안 함으로 설정해야 제목이 보입니다. Windows 버전에 따라 설정 이름이 다를 수 있습니다. 시세는 한 줄로 표시되며 공간이 부족하면 잘립니다.

TP·SL의 소수점 표시는 어떻게 되나요?

포지션 라벨과 관련 툴팁은 소수점 한 자리로 표시합니다. 0이 아닌 값이 0.1보다 작으면 <0.1로 표시합니다. 화면 표시만 간결하게 줄이며, 실제 주문 가격과 수량의 정밀도는 유지합니다.

설치 시 Windows 보안 안내가 표시돼요.

현재 설치 파일은 코드 서명되지 않은 개인 개발용 빌드입니다. Windows에서 게시자를 확인할 수 없다는 안내가 나타날 수 있습니다. 배포 출처와 파일을 확인한 뒤 설치 여부를 결정하세요.

Mac이나 휴대폰에서도 사용할 수 있나요?

현재 이 페이지에서 내려받는 설치 파일은 Windows용입니다. Mac용 빌드 설정도 추가되어 소스가 있다면 Mac에서 DMG를 직접 만들 수 있습니다. Mac용 설치 파일은 아직 이 페이지에서 제공하지 않습니다. 휴대폰에서는 이 다운로드 페이지를 볼 수 있습니다.
